# 데이터 위치:  data/
- input목록
data\오픈소스_컴포넌트목록.xlsx
- output 형식
data\오픈소스_컴포넌트별 취약점목록.xlsx

# 요구 기능
1. 식별된 오픈소스 컴포넌트와 컴포넌트 버전별 보안취약점을 찾아주는 기능 작성
2. 보안취약점이 발견된 오픈소스 컴포넌트을 조치하기 위한 버전을 찾기
3. 조치 버전 제공 시 아래 버전 표기
    - 보안취약점이 해결된 최신 버전
    - 기존 식별된 버전을 기준으로 보안취약점이 해결된 가까운 버전 
4. 버전 표기 예시
 예) 소스 버전 : OpenSSL 0.9.8h 
    해결 가까운 버전 : OpenSSL 0.9.8zh  
    최신 버전 : OpenSSL 3.0.8
